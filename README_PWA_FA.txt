نسخه PWA کافه هناس

قابلیت‌ها:
- نصب روی Android و دسکتاپ
- اجرای تمام‌صفحه مانند اپ
- کار آفلاین پس از اولین بارگذاری
- ذخیره اطلاعات روی دستگاه
- آیکن و صفحه شروع اختصاصی

روش استفاده صحیح:
PWA باید از طریق HTTPS یا localhost اجرا شود. باز کردن مستقیم index.html با file:// امکان نصب Service Worker را نمی‌دهد.

روش ساده انتشار:
1) محتوای این پوشه را در Netlify Drop، GitHub Pages یا هر هاست HTTPS قرار دهید.
2) آدرس را در Chrome اندروید باز کنید.
3) دکمه «نصب اپ» یا گزینه Add to Home screen را بزنید.

برای تست روی ویندوز با Python:
py -m http.server 8080
سپس http://localhost:8080 را باز کنید.
