Henas Cafe OS Cloud + تقویم شمسی

این نسخه:
- دیتابیس PostgreSQL روی Supabase
- ثبت‌نام و ورود با ایمیل/رمز
- فضای کاری مشترک کافه
- همگام‌سازی خودکار اطلاعات بین دستگاه‌ها
- ذخیره محلی برای تحمل قطع اینترنت
- نشانگر وضعیت همگام‌سازی
- تقویم شمسی واقعی برای تمام فیلدهای تاریخ
- ذخیره استاندارد تاریخ در دیتابیس برای گزارش‌گیری صحیح

راه‌اندازی Supabase:
1. در supabase.com یک پروژه بسازید.
2. فایل SUPABASE_SETUP.sql را در SQL Editor اجرا کنید.
3. Project URL و Publishable/Anon Key را از Connect یا Settings > API Keys بردارید.
4. اپ را در GitHub Pages آپلود کنید.
5. در اولین اجرا URL و کلید عمومی را وارد کنید.
6. مدیر ثبت‌نام و فضای کاری «کافه هناس» را ایجاد کند.
7. کد عضویت نمایش‌داده‌شده را به پرسنل بدهید.
8. هر پرسنل با ایمیل خودش ثبت‌نام و با کد عضو شود.

امنیت:
- هرگز Secret Key یا Service Role Key را در GitHub یا مرورگر قرار ندهید.
- فقط Publishable یا Anon Key برای فرانت‌اند مناسب است.
- دسترسی داده‌ها با Supabase Auth و RLS کنترل می‌شود.
- عضویت عمومی فقط نقش staff می‌سازد. ارتقای مدیر فعلاً باید توسط مالک انجام شود.

حالت محلی:
برای آزمایش بدون دیتابیس می‌توان «حالت آزمایشی محلی» را انتخاب کرد، اما داده‌ها بین دستگاه‌ها مشترک نمی‌شوند.

انتشار:
1. ZIP را Extract کنید.
2. همه فایل‌ها، از جمله SUPABASE_SETUP.sql و cloud-config.js را در Repository قرار دهید.
3. Commit changes بزنید.
4. چند دقیقه صبر و سپس Ctrl+F5 اجرا کنید.
