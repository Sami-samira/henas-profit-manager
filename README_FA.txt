پنل پرسنل:

- محاسبه ساعت کار، اضافه‌کاری، کسری و پاداش تارگت

محدودیت نسخه فعلی:

- برای استفاده هم‌زمان از چند گوشی به دیتابیس مرکزی نیاز است.

روش انتشار:
1. ZIP را Extract کنید.
2. فایل‌ها را در ریشه Repository جایگزین کنید.
3. Commit changes را بزنید.
4. 2 تا 3 دقیقه صبر کنید.
5. Ctrl+F5 بزنید یا کش سایت را پاک کنید.
