Henas Cafe OS Pro - PWA

روش انتشار روی GitHub Pages:
1. فایل ZIP را Extract کنید.
2. تمام فایل‌های داخل آن را در ریشه Repository آپلود کنید.
3. Commit changes را بزنید.
4. 2 تا 3 دقیقه صبر کنید.
5. سایت را با Ctrl+F5 باز کنید.
6. اگر نسخه قدیمی ماند، داده و کش سایت را از تنظیمات Chrome پاک کنید.

قابلیت‌ها:
- دستیار باریستا محاوره‌ای
- ورودی صوتی فارسی در مرورگرهای پشتیبانی‌شده
- خواندن صوتی پاسخ
- کتابچه دیجیتال رسپی
- مواد اولیه و بهای تمام‌شده
- هزینه، پرت و موجودی
- تحلیل سود و مهندسی منو
- نصب PWA و کارکرد آفلاین

نکته:
دستیار فعلی به صورت آفلاین و مبتنی بر رسپی‌ها و قواعد داخلی کار می‌کند.
برای پاسخ‌های آزادتر و پیشرفته‌تر می‌توان در نسخه بعد API یک مدل زبانی را متصل کرد.
